# SAE-S3-Developpement-d-une-application

Cette application Java permet à un utilisateur de tester et d'améliorer ses connaissances grâce à des quiz.
Les questions sont organisées par catégories et par niveaux de difficulté.
L'utilisateur peut créer, modifier, supprimer et importer des questions depuis un fichier CSV.
Il peut composer des questionnaires de 5, 10 ou 20 questions selon une catégorie et un niveau choisis.
Les questions et leurs propositions sont présentées dans un ordre aléatoire.
Après chaque test, l'application affiche le score, les corrections et les feedbacks disponibles.
Les dernières tentatives sont conservées afin de pouvoir consulter son historique et refaire un test.
L'application permet aussi de partager des questions entre deux ordinateurs par une communication réseau chiffrée.
